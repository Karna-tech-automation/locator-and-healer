# Locator and Healer

Manifest V3 Chrome extension for Playwright automation engineers.
Finds accurate locators, generates ranked fallbacks, and stores them in a
Page-grouped Object Repository consumable by a Playwright framework.

**Current status:** Phase 0 — scaffolding + smoke test only.

## Prerequisites

- Node.js 20+
- npm 10+
- Chrome 120+
